# Lucid — Stage 1

A low-latency classroom whiteboard foundation for React 19 / Vite 9.

## Included

- Effectively infinite world-space canvas
- Pen drawing with pressure support
- Dashed pencil
- Stroke and area eraser
- Undo / redo
- Five preset colours + custom colour
- One-finger pan
- Two-finger pan + pinch zoom
- Mouse support for desktop testing
- Multi-page whiteboard
- Left/right floating tool rails
- Fullscreen and reset-view controls

## Integration

Copy `src/` files into the existing Lucid project. No extra dependencies are required by this stage.
